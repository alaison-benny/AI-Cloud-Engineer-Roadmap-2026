# AWS EKS Cluster Deployment using Terraform 🚀

Terraform ഉപയോഗിച്ച് AWS-ൽ ഒരു Elastic Kubernetes Service (EKS) ക്ലസ്റ്റർ എങ്ങനെ ഓട്ടോമേറ്റഡ് രീതിയിൽ നിർമ്മിക്കാം.
---

## 📂 Overview

There are 3 steps:
1. **Infrastructure as Code (IaC)**: കോഡ് ഉപയോഗിച്ച് ഇൻഫ്രാസ്ട്രക്ചർ നിർമ്മിക്കുന്നു.
2. **Custom VPC Setup**: ഡിഫോൾട്ട് VPC ഒഴിവാക്കി പുതിയ നെറ്റ്‌വർക്കിംഗ് നിർമ്മിക്കുന്നു.
3. **EKS Managed Node Groups**: വർക്കർ നോഡുകളെ ക്ലസ്റ്ററുമായി ബന്ധിപ്പിക്കുന്നു.

---

## 🏗️ ഉപയോഗിക്കുന്ന ടെറാഫോം ഫയലുകൾ (Terraform Structure)

| ഫയൽ പേര് | വിവരണം |
| :--- | :--- |
| `provider.tf` | AWS റീജിയൻ, ആവശ്യമായ പ്ലഗിന്നുകൾ, ലോക്കൽ വേരിയബിളുകൾ എന്നിവ ഇവിടെ നൽകുന്നു. |
| `vpc.tf` | ക്ലസ്റ്ററിന് വേണ്ടിയുള്ള പുതിയ VPC, Subnets, NAT Gateway എന്നിവ നിർമ്മിക്കുന്നു. |
| `eks.tf` | EKS ക്ലസ്റ്ററിന്റെ പേര്, വേർഷൻ, നോഡ് ഗ്രൂപ്പുകളുടെ സൈസ് (Min, Max, Desired) എന്നിവ ഇതിൽ ഉൾപ്പെടുന്നു. |

---

## 💻 കുബെർനെറ്റീസ് & ടെറാഫോം കമാൻഡുകൾ (Key Commands)

ഓരോ കമാൻഡും എന്തിന് വേണ്ടിയാണെന്ന് താഴെ നൽകുന്നു:

### 1. Terraform Commands
* `terraform init` : ടെറാഫോം വർക്കിംഗ് ഡയറക്ടറി ഇനീഷ്യലൈസ് ചെയ്യാനും ആവശ്യമായ പ്രൊവൈഡർ പ്ലഗിന്നുകൾ ഡൗൺലോഡ് ചെയ്യാനും ഉപയോഗിക്കുന്നു.
* `terraform plan` : ക്ലൗഡിൽ റിസോഴ്സുകൾ നിർമ്മിക്കുന്നതിന് മുമ്പ് എന്തൊക്കെ മാറ്റങ്ങളാണ് സംഭവിക്കാൻ പോകുന്നത് എന്ന് പരിശോധിക്കാൻ ഇത് സഹായിക്കുന്നു.
* `terraform apply` : നമ്മുടെ കോഡ് അനുസരിച്ച് AWS-ൽ യഥാർത്ഥ റിസോഴ്സുകൾ (VPC, EKS) നിർമ്മിക്കാൻ ഈ കമാൻഡ് ഉപയോഗിക്കുന്നു.
* `terraform destroy` : പഠനം കഴിഞ്ഞാൽ അനാവശ്യ ചിലവുകൾ ഒഴിവാക്കാൻ നിർമ്മിച്ച എല്ലാ റിസോഴ്സുകളും ഒറ്റയടിക്ക് ഡിലീറ്റ് ചെയ്യാൻ.

### 2. Kubernetes & AWS CLI Commands
* `aws eks update-kubeconfig --region <region-name> --name <cluster-name>` : നിങ്ങളുടെ ലോക്കൽ മെഷീനിലുള്ള `kubectl`-നെ പുതിയ EKS ക്ലസ്റ്ററുമായി കണക്ട് ചെയ്യാൻ ഈ കമാൻഡ് നിർബന്ധമാണ്. ഇത് `kubeconfig` ഫയൽ അപ്ഡേറ്റ് ചെയ്യുന്നു.
* `kubectl get nodes` : ക്ലസ്റ്ററിലെ നോഡുകൾ (EC2 instances) റെഡിയാണോ എന്ന് പരിശോധിക്കാൻ.
* `kubectl get pods` : നിലവിൽ ക്ലസ്റ്ററിൽ പ്രവർത്തിക്കുന്ന പോഡുകളുടെ വിവരങ്ങൾ അറിയാൻ.
* `kubectl run engine-x --image=nginx` : ക്ലസ്റ്റർ ശരിയായി പ്രവർത്തിക്കുന്നുണ്ടോ എന്ന് ടെസ്റ്റ് ചെയ്യാൻ ഒരു Nginx പോഡ് ക്രിയേറ്റ് ചെയ്യുന്നു.

## 📝 സ്റ്റെപ്പ്-ബൈ-സ്റ്റെപ്പ് പ്രോസസ് (Deployment Steps)

1. **Prerequisites**: AWS CLI, Terraform, kubectl എന്നിവ ഇൻസ്റ്റാൾ ചെയ്യുക.
2. **Initialization**: `terraform init` നൽകി പ്രൊജക്റ്റ് തുടങ്ങുക.
3. **Execution**: `terraform apply` നൽകി 15-20 മിനിറ്റ് കാത്തിരിക്കുക (EKS ക്ലസ്റ്റർ റെഡിയാകാൻ സമയമെടുക്കും).
4. **Connection**: `update-kubeconfig` കമാൻഡ് വഴി ക്ലസ്റ്ററുമായി കണക്ട് ചെയ്യുക.
5. **Testing**: ഒരു സാമ്പിൾ പോഡ് റൺ ചെയ്ത് നോഡുകളുടെ പ്രവർത്തനം ഉറപ്പാക്കുക.
6. **Cleanup**: പഠനത്തിന് ശേഷം `terraform destroy` ഉപയോഗിച്ച് റിസോഴ്സുകൾ റിമൂവ് ചെയ്യുക.
