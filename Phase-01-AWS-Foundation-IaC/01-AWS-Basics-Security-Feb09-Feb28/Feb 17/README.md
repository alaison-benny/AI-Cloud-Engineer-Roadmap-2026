# S3 Bucket Management with Boto3- Python script

ഈ പ്രോജക്റ്റിൽ AWS S3 ബക്കറ്റുകൾ Manage ചെയ്യുന്നതിനായി 3 Python scripts below given
## സ്‌ക്രിപ്റ്റുകളെക്കുറിച്ചുള്ള വിവരങ്ങൾ

1. **`alu-new-bc-created-by-scrpt-2026.py`**:
* Script for creating a new s3 bucket
* ഇതിൽ `us-east-2` റീജിയൺ ഡിഫോൾട്ടായി നൽകിയിരിക്കുന്നു.


2. **`List_S3_buckets_python_script.py`**:
* നിങ്ങളുടെ AWS അക്കൗണ്ടിലുള്ള എല്ലാ ബക്കറ്റുകളുടെയും പേര് ലിസ്റ്റ് ചെയ്യാൻ ulla script.


3. **`list-s3-permission.py`**:
* ബക്കറ്റുകൾ 'Public' ആണോ അതോ 'Private' ആണോ എന്ന് പരിശോധിക്കുന്നു.
* ഇത് 'Public Access Block' സെറ്റിംഗ്‌സ് കൂടി പരിശോധിച്ചാണ് റിസൾട്ട് നൽകുന്നത്.



---

## This python script നിങ്ങളുടെ Ubuntu EC2-ൽ എങ്ങനെ പ്രവർത്തിപ്പിക്കാം?

### Step 1: Python-ഉം Boto3-യും ഉണ്ടെന്ന് ഉറപ്പുവരുത്തുക

ആദ്യം സിസ്റ്റത്തിൽ പൈത്തൺ ഉണ്ടെന്നും ആവശ്യമായ ലൈബ്രറികൾ ഉണ്ടെന്നും ഉറപ്പാക്കുക.

```bash
sudo apt update
sudo apt install python3-pip -y
pip3 install boto3

```

### Step 2: AWS ക്രെഡൻഷ്യൽസ് കോൺഫിഗർ ചെയ്യുക

EC2 ഇൻസ്റ്റൻസിന് S3 ആക്സസ് ഉള്ള ഒരു **IAM Role** നൽകുന്നതാണ് ഏറ്റവും സുരക്ഷിതം. അല്ലെങ്കിൽ താഴെ പറയുന്ന കമാൻഡ് ഉപയോഗിച്ച് നിങ്ങളുടെ Access Key-യും Secret Key-യും നൽകാം:

```bash
aws configure

```

### Step 3: സ്‌ക്രിപ്റ്റ് ഡൗൺലോഡ് ചെയ്യുക അല്ലെങ്കിൽ ക്രിയേറ്റ് ചെയ്യുക

GitHub-ൽ നിന്ന് ക്ലോൺ ചെയ്യുകയോ അല്ലെങ്കിൽ നേരിട്ട് ഫയൽ ക്രിയേറ്റ് ചെയ്യുകയോ ചെയ്യാം. ഉദാഹരണത്തിന്:

```bash
vim list-s3-permission.py
# സ്‌ക്രിപ്റ്റ് പേസ്റ്റ് ചെയ്ത് സേവ് ചെയ്യുക.

```

### Step 4: സ്‌ക്രിപ്റ്റ് റൺ ചെയ്യുക

താഴെ പറയുന്ന കമാൻഡ് ഉപയോഗിച്ച് നിങ്ങൾക്ക് സ്‌ക്രിപ്റ്റ് പ്രവർത്തിപ്പിക്കാം:

```bash
# ബക്കറ്റുകൾ ലിസ്റ്റ് ചെയ്യാൻ
python3 List_S3_buckets_python_script.py

# പെർമിഷനുകൾ പരിശോധിക്കാൻ
python3 list-s3-permission.py

# പുതിയ ബക്കറ്റ് ക്രിയേറ്റ് ചെയ്യാൻ
python3 alu-new-bc-created-by-scrpt-2026.py

```

## ശ്രദ്ധിക്കുക

* **Bucket Name**: ബക്കറ്റ് പേര് നൽകുമ്പോൾ സ്പെഷ്യൽ ക്യാരക്ടറുകൾ ഒഴിവാക്കുക. ബക്കറ്റ് പേര് ഇന്റർനാഷണൽ ലെവലിൽ യുണീക്ക് ആയിരിക്കണം.
* **Permissions**: നിങ്ങളുടെ EC2 മെഷീന് S3 ബക്കറ്റുകൾ ലിസ്റ്റ് ചെയ്യാനും ക്രിയേറ്റ് ചെയ്യാനും ആവശ്യമായ IAM പെർമിഷനുകൾ ഉണ്ടെന്ന് ഉറപ്പുവരുത്തുക.
